# TVLite · شاشتي

شاشة رئيسية خفيفة لأجهزة التلفزيون وأجهزة TV Box القديمة، تشتغل من **Android 5.0** وما فوق، ومكتوبة من الصفر بدون أي مكتبات خارجية (حجم الـ APK أقل من 100 كيلوبايت تقريبًا).

## وش فيها

- ساعة كبيرة مع التاريخ الميلادي والهجري
- مواقيت الصلاة للهفوف بطريقة أم القرى، تنحسب داخل الجهاز بدون إنترنت، مع عدّاد للصلاة القادمة
- الطقس الحالي والعظمى والصغرى (من Open-Meteo، مجاني وبدون مفتاح)
- مباريات الهلال والنصر والاتحاد والأهلي والفتح والقادسية: المباشرة والقادمة وآخر النتائج (دوري روشن، كأس الملك، آسيا)
- صف تطبيقاتك يتحرك بالريموت، وزر للإعدادات
- شاشة توقف تطلع تلقائيًا بعد 10 دقائق بدون استخدام، وتتحرك كل دقيقة عشان ما تحرق الشاشة. وفيها كمان Daydream للأجهزة اللي تدعمه.
- تقدر تخليها الشاشة الرئيسية (Home) للجهاز

## التحميل

كل تعديل على `main` يبني نسخة جديدة تلقائيًا عن طريق GitHub Actions.
نزّل آخر نسخة من هنا: **[TVLite.apk](../../releases/download/latest/TVLite.apk)**

## التثبيت عن طريق adb

```
adb connect 10.206.1.138:5555
adb install -r TVLite.apk
adb shell am start -n com.tvlite.home/.MainActivity
```

عشان تخليها الشاشة الرئيسية: اضغط زر Home في الريموت واختر «شاشتي» ثم «دائمًا».

## تغيير المدينة أو الفرق

- المدينة والإحداثيات: `app/src/main/java/com/tvlite/home/Config.java`
- الفرق والبطولات: `app/src/main/java/com/tvlite/home/Matches.java`

## البناء محليًا

يحتاج JDK 17 و Android SDK:

```
./gradlew assembleRelease
```

ملاحظة: مفتاح التوقيع `app/tvlite.keystore` موجود في المستودع عن قصد، عشان كل نسخة جديدة تقدر تحدّث القديمة على الجهاز بدون حذف. هذا مناسب لتطبيق شخصي، لكن لا تستخدم نفس المفتاح لتطبيق تنشره في المتجر.

مصادر البيانات: الطقس من [Open-Meteo](https://open-meteo.com)، والمباريات من خلاصة ESPN العامة.
